# Sound Control + VoiceMeeter Banana

1. Распакуйте весь архив в обычную папку.
2. Запустите `SoundControlSetup.exe`.
3. Выберите папку Sound Control и нажмите «Установить».

Если Banana уже установлена, будет использована текущая версия. Она не
обновляется и не переустанавливается. Если Banana отсутствует, установщик
запустит оригинальный подписанный установщик VB-Audio. Подтвердите запрос
прав администратора Windows. Для включения новых аудиодрайверов потребуется
перезагрузка — она не запускается автоматически.

Sound Control устанавливается для текущего пользователя, по умолчанию в
`%LOCALAPPDATA%\Programs\SoundControl`, и появляется в меню «Пуск».
Автозапуск Windows можно отключить в установщике или настройках приложения.
У нового пользователя включается запуск Banana вместе с Sound Control;
микрофон, клавиша, выходы и остальные настройки выбираются в приложении.
Существующие настройки сохраняются.

Интернет для установки из этого комплекта не требуется. Для первой настройки
звука откройте микшер Banana, назначьте аппаратный выход A1 и нужный микрофон.
Комплект не меняет стандартные устройства Windows, маршрутизацию и чужие
записи автозапуска автоматически.

VoiceMeeter Banana — отдельное приложение VB-Audio, распространяемое как
donationware. Если оно полезно, автор приглашает поддержать его / оплатить
лицензию. Официальный сайт: https://voicemeeter.com.
Подробности: `THIRD-PARTY-NOTICES.md`.

Удаление: завершите Sound Control, отключите его автозапуск и удалите папку
утилиты. Сохранённые настройки находятся в
`%LOCALAPPDATA%\VoicemeeterMuteTray`. Banana удаляется отдельно штатными
средствами Windows; после удаления её драйверов также нужна перезагрузка.
