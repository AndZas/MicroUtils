# Sound Control — запуск без установки утилиты

Распакуйте архив и запустите `VoicemeeterMuteTray.exe`. Python не требуется.
VoiceMeeter Banana должна быть установлена отдельно. Для установки обоих
приложений скачайте архив `with-Banana` из того же релиза.

Первичная настройка: откройте Banana, назначьте A1 и микрофон, затем в Sound
Control выберите вход/устройство и включите горячую клавишу. Разделы настроек
объяснены в руководстве: https://github.com/AndZas/MicroUtils/tree/main/SoundControl

Профиль: `%LOCALAPPDATA%\VoicemeeterMuteTray`. Закрытие окна может сворачивать
программу в трей; для завершения выберите «Выход».
Переместив EXE, повторно включите автозапуск из новой копии.

компонентах находятся в `licenses` и `THIRD-PARTY-NOTICES.md`.
