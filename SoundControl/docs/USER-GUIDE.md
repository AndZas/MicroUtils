# Руководство Sound Control 1.0

Настраиваемая утилита для **Windows и установленной VoiceMeeter Banana**:
глобальная клавиша mute, восстановление микрофона, перезапуск аудиодвижка при
подключении выбранных выходов и управление фоновым запуском Banana.
Python не требуется для готового EXE. Проверено на Windows 11, Python 3.13 и Banana 2.1.2.2.

## Первый запуск

Запустите `VoicemeeterMuteTray.exe`. Имя EXE сохраняется для совместимости с прежними версиями.
У нового пользователя откроется окно настройки; запуск Banana, скрытие её значка,
автовосстановление и глобальная клавиша первоначально выключены.

1. Запустите Banana самостоятельно или включите её запуск в разделе **Приложение → VoiceMeeter Banana**.
2. В **Микрофон** выберите аппаратный вход 1–3. Первоначально сохраняется уже назначенное
   устройство Banana; если его нет, используется устройство ввода Windows по умолчанию.
   Для изменения достаточно выбрать устройство из списка — оно назначится автоматически.
   При смене номера входа читается его текущее назначение Banana; для пустого входа
   используется микрофон Windows по умолчанию.
3. В **Микрофон → Горячая клавиша** нажмите блок с текущим сочетанием, нажмите нужные
   клавиши и отпустите их все. Сочетание сохранится автоматически; Esc отменяет запись.
   «Сбросить» возвращает `right ctrl`. Включите переключение микрофона.
4. Включите нужные виды восстановления и выберите параметры уведомлений.

Настройки индивидуальны для учётной записи Windows. В исходниках нет выбранного
микрофона, личных идентификаторов устройств или путей другого пользователя.

## Что можно настроить

| Раздел | Параметры |
| --- | --- |
| Микрофон | Клавиша или сочетание до четырёх клавиш; запись сочетания; включение; вход Banana 1–3; выбор устройства Windows или текущего назначения Banana; автовосстановление и его параметры |
| Аудиовыходы | Выходы A1/A2/A3; только Bluetooth A2DP или любые аудиоустройства; ожидание готовности; пауза между перезапусками |
| Уведомления | Показ и длительность сообщений; отдельная громкость и mute звуков микрофона и уведомлений; три встроенных сигнала и собственные WAV |
| Приложение | Только трей / окно и трей / только окно; поведение крестика; запуск с Windows; запуск Banana; скрытие её значка; автоматический или заданный путь к EXE |

Переключатели и числовые значения сохраняются при изменении, без дополнительных кнопок.
Колесо мыши над числовым полем и списком прокручивает страницу, не меняя настройку.
При переходе в раздел открывается его начало. Индикатор подключения Banana внизу
боковой панели открывает микшер. При mute значок микрофона перечёркнут.
Точка подключения показывается только в боковой панели; в трее и на панели задач
используется более крупный заполненный микрофон. Подсказка трея — название и версия.
Меню по правой кнопке в трее оформлено в стиле окна; обычное нажатие открывает настройки.

У звуков микрофона и уведомлений независимые ползунки 0–100%. Кнопка динамика
включает/выключает группу, сохраняя её уровень. Перетаскивание ползунка не
меняет звук Windows или Banana; громкость применяется к самим WAV. Громкость
сохраняется при отпускании ползунка, при управлении клавишами — сразу.
Кнопки с треугольником позволяют прослушать каждый сигнал на выбранной громкости.
Во время mute группы предпрослушивание тоже отключено.

Встроенные сигналы: две короткие ноты вниз для mute, те же ноты вверх для unmute,
двухтональное уведомление. Они синтезированы специально для Sound Control,
без сторонних сэмплов; исходник — `generate_sounds.py`, записи — `audio_assets`.
Свой файл: PCM WAV 8/16/24/32 бит до 32 МБ. При недоступном или неподдерживаемом
файле используется собственный встроенный сигнал с той же громкостью.
Проигрывание идёт на отдельном потоке. Текущий сигнал завершается естественно;
при частых нажатиях сохраняется только последний ожидающий сигнал. Это исключает
резкие обрывы волны при повторном запуске и накопление очереди. Для пользовательского
WAV следующий сигнал также ждёт окончания текущего файла.
Вывод выполняется напрямую через WASAPI в общем режиме. Буфер 500 мс заранее
вмещает каждый встроенный сигнал целиком; звуковой канал переиспользуется между
сигналами и останавливается на время простоя. Перед/после сигнала добавляется
короткий участок тишины, сами WAV не изменяются. Для отличающейся частоты/числа
каналов используется качественное преобразование Windows. После сна или смены
стандартного выхода канал создаётся заново. Перезапуск Banana и изменение
её буферов для этого не требуются.

Заголовок и рамка используют штатное управление Windows: привязка к краям,
Snap Layouts, разворачивание двойным щелчком по заголовку и растягивание по вертикали
двойным щелчком по верхней/нижней границе. Двойной щелчок по боковой границе
растягивает окно по ширине с сохранением высоты; повторный возвращает прежнюю ширину.
Перетаскивание заголовка возвращает обычную ширину под курсором; разворачивание
и последующее восстановление также возвращают размер до растягивания.
В развёрнутом или закреплённом состоянии углы прямые. Минимальный размер — 480×420.
Появление системных панелей Snap зависит от настроек Windows; утилита их не меняет.
Версия задаётся в `version.APP_VERSION` и увеличивается с каждой партией исправлений;
локальная и публичная сборки одной партии используют одинаковый номер.
Первый стабильный выпуск — `1.0.0`. Исправления повышают последнее число,
крупные совместимые дополнения — среднее; новый старший номер обозначает несовместимые изменения.

При сне наблюдение за аудиоустройствами приостанавливается. После пробуждения
утилита заново создаёт наблюдатель Windows Core Audio, восстанавливает значок
трея и сбрасывает состояние зажатых клавиш. Сессия Remote API остаётся той же:
пробуждение не вызывает дополнительный Login. Перезапуск Explorer также
восстанавливает значок. При пропущенном событии пробуждения используется разрыв
в таймере; таймер не запрещает сон и не будит компьютер. Неожиданная ошибка
рабочего потока записывается в журнал и запускает его заново с корректным Logout.
Для диагностики нативных ошибок используется локальный `native-errors.log`.

Сочетание сохраняется после отпускания всех записываемых клавиш. Список микрофонов
обновляется при открытии. Сохранённое устройство не заменяется при отключении или
новом запуске. Выбор устройства и входа применяется автоматически. Пока назначение
не подтверждено Banana, селекторы блокируются; при ошибке возвращается сохранённый выбор.
В режиме **Только окно** закрытие окна завершает утилиту; скрытого процесса без доступного окна не остаётся.
В остальных режимах крестик может оставлять программу в трее.

Интерфейс использует **Qt 6 / PySide6 Essentials**: сглаженные векторные элементы,
скруглённые карточки и четыре раздела боковой навигации. На Windows 11 22H2 и новее
системный Desktop Acrylic размывает фон за окном; при недоступности эффекта
сохраняется непрозрачный тёмный фон. Прозрачность зависит от настроек и возможностей Windows.
Перетягивание разделителя переключает боковую панель между двумя фиксированными
состояниями: полным и компактным с иконками. Переключение происходит во время движения,
с порогом против дрожания; произвольная ширина не сохраняется даже при потере фокуса.
В узком окне панель сворачивается автоматически.
Нажатие на основной значок микрофона переключает mute; красный значок означает mute.
Путь к WAV или EXE выбирается нажатием на сам блок пути с иконкой папки; это кнопка,
а не текстовый ввод. Под журналом отображается номер текущей сборки в обоих режимах панели.
Маленькая точка рядом со значком отдельно показывает подключение устройства, в том
числе когда микрофон выключен: зелёная — подключён, красная — отключён, жёлтая — проверка/восстановление.
Фон не снимается скриншотами и не размывается на CPU. Изменение размера выполняет
оконный менеджер Windows; скрытое или свёрнутое окно не обновляет свои статусы.

Меню трея короткое: горячая клавиша, восстановление микрофона, открытие Banana,
настройки и выход. Индикаторы в окне показывают mute и подключение выбранного устройства.

## Микрофон и клавиша

Mute изменяет только выбранный `Strip[0..2]`. Состояние считывается из Banana перед
переключением. Удержание клавиши не вызывает повторных переключений; звук проигрывается
после подтверждения. При записи нового сочетания переключение mute приостановлено.
Правый и левый Ctrl различаются. Сочетания, уже перехваченные другой программой,
могут не доходить до утилиты.

Выбор устройства Windows назначает его на указанный вход через **WDM**.
При первоначальном определении уже назначенного устройства сохраняется его драйвер
MME/WDM/KS. При одинаковых именах устройств назначение отклоняется: переименуйте
одно из них в Windows. ASIO-входы без отдельной конечной точки Windows этим выбором
не управляются.

Восстановление отслеживает присутствие устройства, а не тишину. После возвращения
микрофона выполняется снятие назначения, пауза, повторное назначение и перезапуск
аудиодвижка. Ручное назначение другого устройства не перезаписывается.
После исчерпания попыток программа сообщает о проблеме; ручной запрос позволяет повторить цикл.
Весь звук Banana кратко прерывается во время перезапуска движка.

## Аудиовыходы

Назначения выбранных A1/A2/A3 считываются из Banana, а состояние устройств — из Windows.
Утилита не привязана к марке наушников или колонки. В режиме Bluetooth отслеживаются
стереовыходы A2DP; режим **Любые аудиоустройства** также подходит, например, USB-устройствам.
Устройство не переназначается автоматически на другой выход.

Перезапуск выполняется после подключения и ожидания готовности. Пока устройства выключены,
повторных перезапусков нет. Близкие подключения объединяются; действует пауза между
перезапусками. Восстановление микрофона имеет приоритет, чтобы не перезапускать движок дважды.
Изменение списка отслеживаемых выходов не воспроизводит старые подключения.
Выбор устройства по умолчанию и маршрутизация Windows остаются самостоятельными настройками.

## Banana в фоне

Если включён запуск Banana, утилита запускает её с `-h` и ждёт готовности API.
Работающий экземпляр используется повторно. При скрытом значке открывайте микшер через
**VoiceMeeter Banana** в меню утилиты или кнопку в разделе **Приложение**.
Крестик Banana возвращает её в фон. **Выход** из утилиты возвращает родной значок Banana
и оставляет её аудиодвижок работать. Завершение Banana через её родное меню не вызывает
бесконечного автоматического перезапуска; её можно снова открыть из утилиты.

Новый путь к EXE применяется после перезапуска утилиты. Для полного отключения управления
фоновым запуском и значком выключите оба переключателя в разделе «Приложение».
Скрытие значка проверено с Banana 2.1.2.2. Если будущая версия изменит его регистрацию,
эта часть интеграции может потребовать обновления.

## Данные и обновление

Профиль: `%LOCALAPPDATA%\VoicemeeterMuteTray\settings.json`.
Журнал с ротацией: `%LOCALAPPDATA%\VoicemeeterMuteTray\app.log`.
Пример без личных данных — [config.example.json](../config.example.json).

Старый профиль автоматически переносится в схему 3: сохраняются выбранный микрофон,
первый вход, правый Ctrl, параметры Banana и прежнее отслеживание Bluetooth A2/A3.
Резервная копия старого JSON создаётся рядом. Два прежних поставляемых сигнала
заменяются встроенными только при совпадении SHA-256; выбранные пользователем
WAV сохраняются. Добавляются независимые уровни громкости. Новый пользователь
получает общие первоначальные настройки.
Повреждённый JSON сохраняется отдельной копией перед восстановлением настроек.
При ручном редактировании JSON сначала завершите утилиту.

Автозапуск добавляется только по выбору пользователя в HKCU Run.
Существующие сторонние записи автозапуска Banana публичная версия автоматически не удаляет.
После переноса EXE включите автозапуск заново из перемещённой копии.


## Если возникла проблема

- **Banana не подключена.** Проверьте, установлена ли она, и запустите микшер. При необходимости задайте путь в разделе «Приложение». После установки драйвера перезагрузите Windows.
- **Клавиша не срабатывает.** Включите её переключатель, заново запишите сочетание и проверьте, не перехватывает ли его другое приложение. Сочетания в окне с повышенными правами могут потребовать такого же уровня прав у утилиты.
- **Устройство пропало.** Проверьте кабель/USB/Bluetooth. Включите восстановление или выберите «Восстановить микрофон» в трее. Программа не может исправить физическую неисправность разъёма.
- **Выход не слышно.** Устройство должно быть назначено на нужный A1/A2/A3 в Banana; проверьте маршрутизацию в самом микшере. Sound Control не переназначает системный выход Windows.
- **Звук сигнала выключен.** Проверьте кнопку динамика и уровень громкости в разделе уведомлений, затем нажмите кнопку прослушивания.
- **После обновления странное состояние.** Завершите работающую копию через «Выход», откройте новую. Сохранённый профиль удалять не нужно.

Журнал открывается кнопкой «Журнал событий». Для отчёта об ошибке укажите версию
Sound Control, Windows и Banana, шаги воспроизведения и относящийся к проблеме фрагмент журнала.

## Что программа не делает

Программа не является аудиодрайвером, не заменяет Banana, не выбирает маршрутизацию
за пользователя и не обеспечивает универсальный перехват аппаратных кнопок гарнитур.
Выпуск ориентирован на Banana; Standard/Potato, Win32 и отдельная ARM64-сборка
не заявлены как поддерживаемые. Громкость A1 с кнопок конкретных гарнитур в этот выпуск не входит.
