# MicroUtils

Небольшие утилиты, которые делают повседневную работу за компьютером удобнее.
У каждого проекта своя папка, документация, версия и набор готовых файлов для скачивания.

## Проекты

| Утилита | Для чего | Платформа | Документация |
| --- | --- | --- | --- |
| **[Sound Control](SoundControl/)** | Горячая клавиша микрофона, восстановление устройств и управление VoiceMeeter Banana | Windows 11 x64 | [Обзор и загрузка](SoundControl/README.md) · [Руководство](SoundControl/docs/USER-GUIDE.md) |

Другие утилиты будут добавляться в этот каталог по мере готовности.

## Загрузка и обновления

Готовые EXE, установочные комплекты и архивы исходников размещаются в
**[GitHub Releases](https://github.com/AndZas/MicroUtils/releases)**.
Название релиза и тег содержат имя утилиты: например, `sound-control-v1.0.0`.
Версии разных проектов независимы друг от друга.

Чтобы получать уведомления, используйте **Watch → Custom → Releases** на странице репозитория.
В Git хранятся исходники, тесты и документация; сборки и пользовательские данные в историю не включаются.
